# Decisions

Judgement calls made during the 2026 rebuild, where the spec was silent or two parts of it pulled apart.

## Build and hosting

- **Astro 7, static output, Preact islands.** Section 4.3 names the Astro config, and sections 17 to 23 were missing, so I chose the simplest stack that matches: every route is a real HTML file (`build.format: 'file'`), and figures hydrate with `client:visible`. Preact keeps the hero island well under 15 KB gzipped.
- **`vercel.json`** pins the framework to Astro, the build command to `npm run build`, the output to `dist`, and sets `cleanUrls` and `trailingSlash: false`. So `/lab/pipeline` serves `lab/pipeline.html`, and `/lab/pipeline/` redirects. This overrides whatever the Vercel dashboard has set, so the Vite preset from the old site cannot break the build.
- **Redirects** for `/lab/tokenizer`, `/lab/attention` and `/lab/levenshtein` come from Astro's `redirects` option. Each writes a small `noindex` page that keeps the `#lab` fragment.
- **`npm run build` fails on a broken link.** `scripts/check-links.mjs` checks every internal link and fragment in `dist/`, and refuses outbound links that are not on a short list of known destinations.
- **The build-time number checks are Vitest suites** (`src/lib/forecast.test.ts` and others). They assert every headline number in section 13 against the data files. Run `npm test` before deploying. Vercel runs only the build.
- **Data files are generated by `scripts/build_data.py`** from local checkouts of the project repositories, then committed. The site build never needs those repositories.
- **Orchestrator tool names come from the registry** (`backend.main.get_all_tool_specs()`), not from `docs/mcp_tool_definitions.txt`. The text file drops the `linear_`, `github_` and `perplexity_` prefixes, so the anchor tools in the routing rule would not have matched it.

## Design

- **Badge explanations sit in a line under each figure title, on every screen size.** On lab pages the left margin holds the sticky "On this page" list and the project facts, so it cannot also hold a note beside each figure.
- **Wide figures extend over the margin column from 1024 px** and cover the sticky list while they pass. Without this, the pipeline explorer is too cramped at 1024 to 1279 px.
- **Figure internals use container queries**, so a figure lays out by its own width, not the window's.
- **Signal cells are 28 px** so that their letters can be 14 px, the site's minimum text size.

## Content

- **Items marked "(confirm)" are behind switches** in `src/content/site.ts`, all off, as section 3 requires. See OPEN_QUESTIONS.md.
- **"No order book" is left out of the stock simulator's limits.** Section 16.3 gives it as copy, but section 3.10 says an order book must never appear on the site. The limit now reads "There are no fees and no real companies."
- **Briefing citations are drawn as an editable value plus a numbered chip.** Where the code wrote the same number just before its citation, the number is shown once, as the editable value.
- **"Break a citation" changes 18.0 to 21.0 on 14 March.** On 15 and 21 March it adds 3 to that day's premium, because those briefings have a different premium.
- **The forecast explorer's touch support** is written by hand: one finger pans, two fingers pinch to zoom. uPlot has neither built in.
- **The MaxSAT port** keeps `exercise3.py`'s structure and replaces Python's `random` with the seeded `mulberry32`, now in `src/lib/rng.ts`. `stockSim.ts` re-exports it, so the stock simulator's tests are unchanged.
- **Analytics stay off** (`site.analytics = false`). Nothing is loaded.
